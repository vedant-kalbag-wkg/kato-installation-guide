\section*{How to use this guide}
\markright{How to use this guide}

This guide covers \textbf{building a kiosk machine}: installing FreedomPay
Freeway Commerce Connect (FCC), applying the WeKnow configuration and PAL
bundle, and confirming the card terminal is working. It is done
\textbf{once per machine}, by IT, before the kiosk is configured for a
site.

Once this guide is finished, the machine is ready to be configured and
deployed --- see the companion \emph{Kato Kiosk Configuration Guide}.

\section{Install FreedomPay FCC}

Skip to \S\ref{sec:verify} if FCC is already installed on this machine and
you only need to confirm it is healthy.

\begin{enumerate}
  \item Run \wpath{FreewayCommerceConnect.exe} as an admin user.

  \item \textbf{Skip the activation step} of the Remote Update Service
        (RUS).

  \item Choose a \textbf{Custom} installation, ticking the features shown
        below.
\end{enumerate}

\screenshot[0.50]{fcc-custom-features}{Custom Setup feature tree --- \textbf{Freeway POI Drivers} and \textbf{Freeway Server Service} ticked, everything else left clear.}

\begin{center}

Binaries \& config &
\wpath{C:\textbackslash Program Files (x86)\textbackslash FreedomPay\textbackslash FreewayCommerceConnect}\\
\rowcolor{weknowgreyL}
Logs &
\wpath{C:\textbackslash ProgramData\textbackslash FreedomPay\textbackslash Freeway Commerce Connect\textbackslash log}\\
\end{tabularx}
\end{center}

% 3  CONFIG + PAL
%=====================================================================
\section{Apply the WeKnow configuration}

\begin{enumerate}
  \item Open the Registry Editor and \textbf{delete} the key\\
        \wpath{HKEY\_LOCAL\_MACHINE\textbackslash SOFTWARE\textbackslash Freedompay\textbackslash Atlas\textbackslash PAL}

  \item Copy the UK \wpath{config} and \wpath{PAL} folders into\\
        \wpath{C:\textbackslash Program Files (x86)\textbackslash FreedomPay\textbackslash FreewayCommerceConnect}

  \item Restart the services in this order:
        \textbf{remote $\rightarrow$ server $\rightarrow$ client}.
\end{enumerate}

% 4  VERIFY
%=====================================================================
\section{Verify the build}\label{sec:verify}

Do not hand the machine on until all four checks below pass.

\begin{enumerate}
  \item In the Windows Services app, confirm both
        \wpath{FreewayClientService} and \wpath{FreewayServerService}
        show \textbf{Running}.

  \item Open the newest log file in\\
        \wpath{C:\textbackslash ProgramData\textbackslash FreedomPay\textbackslash Freeway Commerce Connect\textbackslash log}\\
        and confirm the latest timestamp for \textbf{Lane Open}.

  \item In the same log, confirm the regional configuration package
        reached the terminal --- look for \emph{Successfully pushed}.
\end{enumerate}

\screenshot[0.94]{fcc-log-palpush}{\emph{Successfully pushed} --- the regional config package reached the terminal.}

\begin{enumerate}\setcounter{enumi}{3}
  \item Confirm the terminal accepted and wrote it --- look for a
        \textbf{PalWriteSucceeded} event.
\end{enumerate}

\screenshot[0.94]{fcc-log-palwrite}{\emph{PalWriteSucceeded} --- the terminal accepted and wrote the package.}

\begin{wkinfo}[Done when]
Both services are running, and the log shows \textbf{Lane Open}, a
successful package push and a \textbf{PalWriteSucceeded} at the latest
timestamp. The machine is now ready for the \emph{Kato Kiosk
Configuration Guide}.
\end{wkinfo}

% 5  TROUBLESHOOTING
%=====================================================================
\section{When things go wrong}

\begin{center}
\renewcommand{\arraystretch}{1.35}\small
\begin{tabularx}{\textwidth}{L{50mm} X}
\rowcolor{weknownight}\color{white}\textbf{Symptom} &
\color{white}\textbf{First thing to try}\\
No \emph{Lane Open} in the log &
The terminal is not being detected. Check the cable, restart the client
service, then power-cycle the terminal.\\
\rowcolor{weknowgreyL}
No \emph{Successfully pushed} or \emph{PalWriteSucceeded} &
Confirm the \wpath{Atlas\textbackslash PAL} registry key was deleted
\emph{before} the config and PAL folders were copied in, then restart the
services in order (remote $\rightarrow$ server $\rightarrow$ client).\\
Services will not stay running &
A partially copied bundle is the usual cause. Recopy the \wpath{config}
and \wpath{PAL} folders and restart the services in order.\\
\end{tabularx}
\end{center}

\begin{wkinfo}[Still stuck?]
Zip the whole \wpath{log} folder, note the workstation serial and the
terminal serial, and raise it with the WKG Technology team before
changing anything else.
\end{wkinfo}

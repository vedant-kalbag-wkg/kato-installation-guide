\section*{How to use this guide}
\markright{How to use this guide}

This guide covers \textbf{configuring a kiosk for a specific
installation}. It has two parts, split by who does the work:

\begin{center}
\renewcommand{\arraystretch}{1.35}\small
\begin{tabularx}{\textwidth}{L{20mm} L{34mm} X}
\rowcolor{weknownight}\color{white}\textbf{Part} &
\color{white}\textbf{Who} & \color{white}\textbf{What}\\
\textbf{Part 1} & Account Manager &
Create the location, kiosk and installation record in Command Centre,
clear the prep checks, and hand the Kiosk ID and API key to IT.\\
\rowcolor{weknowgreyL}
\textbf{Part 2} & IT &
Install the Kato app on the machine using those credentials, and lock the
machine into kiosk mode.\\
\end{tabularx}
\end{center}

\begin{wkwarn}[The machine must already be built]
This guide assumes FreedomPay FCC and the PAL packages are installed and
verified on the machine. If that has not been done, work through the
\emph{Kato Kiosk Setup Guide} first --- the prep checks in Part~1 cannot
honestly be cleared until it is.
\end{wkwarn}

\begin{wkinfo}[Golden rules]
\begin{itemize}
  \item The \textbf{API key is shown once}. Copy it the moment you
        generate it, or you will have to generate a new one.
  \item The \textbf{Kiosk ID} and the \textbf{Workstation ID} are
        different things --- see \S\ref{sec:ids}.
  \item Do not clear a prep check you have not actually verified. It is
        the only thing standing between a half-built kiosk and a live
        one.
\end{itemize}
\end{wkinfo}

\section{Before you start}

\subsection{Minimum information needed for a location}

The Account Manager must have all of the following for the location
before an installation can be created. If any are missing, chase them
first.

\begin{center}
\renewcommand{\arraystretch}{1.3}\small
\begin{tabularx}{\textwidth}{X X}
\rowcolor{weknowgreyL}
\emptybox\ Hotel name & \emptybox\ Timezone\\
\emptybox\ Products to enable & \emptybox\ VAT / Tax ID\\
\rowcolor{weknowgreyL}
\emptybox\ Currency & \emptybox\ Tax entity name\\
\emptybox\ Banking details (in full) & \\
\end{tabularx}
\end{center}

\begin{wkwarn}[Legacy fields --- not required]
\textbf{RPS customer code} and \textbf{outlet code} are legacy fields.
Do not chase the site for them.
\end{wkwarn}

\subsection{Two identifiers, two different things}\label{sec:ids}

\begin{center}
\renewcommand{\arraystretch}{1.35}\small
\begin{tabularx}{\textwidth}{L{34mm} X}
\rowcolor{weknownight}\color{white}\textbf{Identifier} &
\color{white}\textbf{What it is}\\
\textbf{Kiosk ID} &
A UUID generated by Command Centre when the kiosk record is created. The
app uses it to identify itself to the server.\\
\rowcolor{weknowgreyL}
\textbf{Workstation ID} &
The physical machine label, e.g.\ \wpath{WKG-POS-617}. Also entered as the
kiosk's serial number in Command Centre.\\
\end{tabularx}
\end{center}

Both go into the install command in Part~2 --- do not swap them.

\section{Part 1 --- Command Centre \role{Account Manager}}

Done from any machine with a browser. You are creating the kiosk record,
clearing its prep checks, collecting the two credentials IT will need, and
scheduling the installation.

\subsection{Create the location and the kiosk}

\begin{enumerate}
  \item Open \href{https://command.weknow.technology}{Command Centre}
        and sign in. Ask the WKG Technology team if you do not have an
        account.

  \item Go to \href{https://command.weknow.technology/locations}{Locations}
        and create the location, working down the hierarchy:
        \textbf{Country $\rightarrow$ Region $\rightarrow$ City
        $\rightarrow$ Location}. Open it and \textbf{copy the Location
        ID} --- you need it when you create the installation record.
\end{enumerate}

\screenshot[0.60]{cc-location-id}{The location Overview tab. Use the copy icon next to \textbf{Location ID}.}

\begin{enumerate}\setcounter{enumi}{2}
  \item \emph{Only if required:} create a group from
        \href{https://command.weknow.technology/groups}{Groups}. Groups
        are either \textbf{location groups} or \textbf{kiosk groups} ---
        use them to apply shared configuration to several sites or several
        kiosks at once. Skip this for a single standalone kiosk.

  \item Go to \textbf{Kiosks} and select \textbf{Add Kiosk}:
    \begin{itemize}
      \item \textbf{Name} --- how the kiosk is referred to operationally,
            e.g.\ \emph{T2/T3 Tunnel - 2}.
      \item \textbf{Serial number} --- the workstation label,
            e.g.\ \wpath{WKG-POS-617}.
      \item \textbf{Hardware model} --- e.g.\ \emph{K10/20}.
      \item \textbf{Firmware version} --- e.g.\ \emph{1.0.0}.
    \end{itemize}
    Then select \textbf{Create Kiosk}.
\end{enumerate}

\screenshot[0.50]{cc-add-kiosk}{Add Kiosk. The kiosk is created unassigned --- it is tied to a location by the installation record.}

\begin{enumerate}\setcounter{enumi}{4}
  \item The new kiosk appears as \textbf{In Stock}. That is expected ---
        it stays In Stock until it is installed.
\end{enumerate}

\subsection{Set the payment credentials}

Set the FreedomPay \textbf{Store ID (StID)} and \textbf{Terminal ID
(TID)} in the kiosk configuration, so payment requests are signed for the
correct merchant.

\subsection{Clear the prep checks}

Open the kiosk and go to the \textbf{Edit} tab. Mark the prep checks
\textbf{Complete} to confirm the kiosk is ready to config and install.

\screenshot[0.86]{cc-prep-checks}{Prep checks on the kiosk Edit tab.}

Before clearing them, verify with IT that:

\begin{itemize}
  \item all the hardware is plugged in and working --- printer, PDQ,
        sensors and scanners;
  \item FreedomPay has been installed, and the
        \wpath{FreewayClientService} and \wpath{FreewayServerService} are
        running.
\end{itemize}

\subsection{Collect the credentials for IT}

\begin{enumerate}
  \item On the kiosk's \textbf{Overview} tab, \textbf{copy the Kiosk ID}.
\end{enumerate}

\screenshot[0.58]{cc-kiosk-id}{Kiosk Overview --- copy the \textbf{Kiosk ID}.}

\begin{enumerate}\setcounter{enumi}{1}
  \item Switch to the \textbf{API keys} tab and select \textbf{Generate
        API key}. This is the key the kiosk uses to authenticate to the
        server.
\end{enumerate}

\screenshot[0.56]{cc-api-key}{Kiosk API keys. Generate the key here.}

\begin{wkwarn}[Copy the API key now]
The full key is displayed \textbf{only once, at creation}. Paste it
somewhere safe --- your password manager or the install ticket --- until
the installation is finished. If you lose it, generate a new one; the old
key cannot be recovered.
\end{wkwarn}

\begin{wkinfo}[Hand over to IT]
Send IT four things: the \textbf{Kiosk ID}, the \textbf{API key}, the
\textbf{Workstation ID} (\wpath{WKG-POS-XXX}), and the printer's COM port
if it is not the standard \wpath{COM8}. Send the API key by a private
channel, and delete it from that channel once the install is confirmed
working.
\end{wkinfo}

\subsection{Create the installation record}

The installation record ties the kiosk to its location and moves it out of
\emph{In Stock}.

\begin{enumerate}
  \item Go to
        \href{https://command.weknow.technology/installations}{Installations}
        and select \textbf{Add Installation}.

  \item Complete the form:
    \begin{itemize}
      \item \textbf{Kiosk} --- the kiosk you created above.
      \item \textbf{Location ID} --- the UUID copied earlier.
      \item \textbf{Planned date} --- the installation date.
      \item \textbf{Hardware model} and \textbf{Serial number} --- must
            match the kiosk record.
      \item \textbf{Installer name}, \textbf{Installer contact} and
            \textbf{Installation company}.
      \item \textbf{Notes} --- anything the engineer on site needs to
            know, e.g.\ \emph{``Install near main entrance''}.
    \end{itemize}

  \item Select \textbf{Create Installation}.
\end{enumerate}

\screenshot[0.50]{cc-add-installation}{Add Installation --- links the kiosk to its location and records who is installing it.}

\begin{wkinfo}[Done when]
The kiosk record exists with its prep checks cleared, the installation
record is created, and IT have the Kiosk ID, API key and Workstation ID.
\end{wkinfo}

\clearpage
\section{Part 2 --- Install and lock the kiosk \role{IT}}

You need the Kiosk ID and API key from the Account Manager before you
start. The machine must already be built per the \emph{Kato Kiosk Setup
Guide}.

\subsection{Install the Kato app}

Done \textbf{signed in as \wpath{SelfBooker}} --- the account the kiosk
runs as.

\begin{enumerate}
  \item Sign in to Windows as \wpath{SelfBooker}.

  \item Open \textbf{PowerShell} in the folder containing the installer
        and run the silent install, substituting your four values:
\end{enumerate}

\begin{lstlisting}
& ".\Kiosk Setup 1.0.0.exe" /S `
  /KIOSKID={KIOSK_ID_FROM_COMMAND_CENTRE} `
  /WORKSTATIONID={WKG-POS-XXX} `
  /APIKEY={API_KEY_FROM_COMMAND_CENTRE} `
  /PRINTER=COM8
\end{lstlisting}

\begin{center}
\renewcommand{\arraystretch}{1.3}\small
\begin{tabularx}{\textwidth}{L{34mm} X}
\rowcolor{weknownight}\color{white}\textbf{Switch} &
\color{white}\textbf{Value}\\
\wpath{/S} & Silent install --- no prompts. Always used.\\
\rowcolor{weknowgreyL}
\wpath{/KIOSKID} & The Kiosk ID from the Account Manager.\\
\wpath{/WORKSTATIONID} & The machine label, e.g.\ \wpath{WKG-POS-617}.\\
\rowcolor{weknowgreyL}
\wpath{/APIKEY} & The API key from the Account Manager.\\
\wpath{/PRINTER} & The printer's COM port. \wpath{COM8} on a standard
build --- confirm in Device Manager if printing fails.\\
\end{tabularx}
\end{center}

\begin{enumerate}\setcounter{enumi}{2}
  \item Confirm the app wrote its identity file. Open
        \wpath{kiosk-identity.json} and check the Kiosk ID, workstation ID
        and API key are present and correct. If the file is missing,
        create it before continuing --- the app will not connect without
        it.

  \item Sign out of \wpath{SelfBooker}, then sign in as \wpath{WKGAdmin}
        for the lockdown below.
\end{enumerate}

\subsection{Lock the machine into kiosk mode}

The Shell Launcher utility replaces the Windows desktop with the Kato app
for the \wpath{SelfBooker} account, so the machine boots straight into the
kiosk and there is no desktop to escape to.

\begin{enumerate}
  \item Signed in as \wpath{WKGAdmin}, run\\
        \wpath{C:\textbackslash Kiosk\textbackslash SSM25\_files\textbackslash Shell-Launcher-Utilities\textbackslash SLUtility.exe}

  \item Select \textbf{Disable User Shell}.

  \item \textbf{Close and reopen} \wpath{SLUtility}. It needs the restart
        to pick up the change --- do not skip this.

  \item Select the \wpath{SelfBooker} user and change the shell path to
        the app, leaving the default \textbf{Action 3}:\\
        \wpath{C:\textbackslash Users\textbackslash SelfBooker\textbackslash AppData\textbackslash Local\textbackslash Programs\textbackslash Kiosk\textbackslash Kiosk.exe}

  \item Select \textbf{Set User Shell}.

  \item Select \textbf{Enable Shell Launcher}.

  \item Sign out of \wpath{WKGAdmin} and sign in as \wpath{SelfBooker}.
        The Kato app should launch full screen with no desktop behind it.
        Reboot once to confirm it comes back the same way.
\end{enumerate}

\begin{wkwarn}[Order matters]
Disable $\rightarrow$ restart the utility $\rightarrow$ set the path
$\rightarrow$ set shell $\rightarrow$ enable. Do not set the shell before
restarting \wpath{SLUtility}.
\end{wkwarn}

\begin{wkinfo}[Done when]
The machine reboots straight into the Kato app as \wpath{SelfBooker}, with
no visible desktop, taskbar or file explorer.
\end{wkinfo}

\section{When things go wrong}

\begin{center}
\renewcommand{\arraystretch}{1.35}\small
\begin{tabularx}{\textwidth}{L{50mm} X}
\rowcolor{weknownight}\color{white}\textbf{Symptom} &
\color{white}\textbf{First thing to try}\\
Machine boots to the Windows desktop, not the app &
The \wpath{SLUtility} sequence was not followed. Redo it in order,
restarting the utility between \emph{Disable User Shell} and setting the
path.\\
\rowcolor{weknowgreyL}
App launches but will not connect &
Check \wpath{kiosk-identity.json}: wrong Kiosk ID, or an API key that was
regenerated after the install. Generate a fresh key and reinstall with the
new value.\\
Installer runs but nothing appears &
The switches are case-sensitive and the backtick line continuations must
be the last character on each line. Retype the command rather than
pasting it from a chat client.\\
\rowcolor{weknowgreyL}
Printer does nothing &
\wpath{/PRINTER} was set to the wrong COM port. Confirm the port in Device
Manager and reinstall with the correct value.\\
Prep checks will not clear &
They are marked manually on the kiosk \textbf{Edit} tab --- they do not
clear themselves when the underlying condition is met.\\
\rowcolor{weknowgreyL}
Payment fails on the test transaction &
That is a machine-build issue, not a configuration one. See the
\emph{Kato Kiosk Setup Guide}.\\
\end{tabularx}
\end{center}
